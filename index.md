# Agent Town Poster

Agent Town Poster is a small personal app that uploads short video clips to my own YouTube channel, **Caught In Haishin** (@caughtinhaishin).

It runs only on my own computer. It is not offered to the public, and nobody else signs in to it.

What it does:

- Uploads clips I have approved to my channel as private videos
- Adds a title, description and tags to each upload

I review every upload and decide when it becomes public.
