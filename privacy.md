# Privacy Policy for Agent Town Poster

Last updated: October 23, 2026

Agent Town Poster is a personal app used only by me, the owner of the YouTube channel Caught In Haishin. It is not offered to anyone else.

## What data the app uses

- It asks Google for permission to upload videos to my own YouTube channel (the youtube.upload permission).
- It keeps the sign-in token on my own computer so it can keep uploading. The token is never shared or sent anywhere except to Google.

## What the app does not do

- It does not collect, store or share personal data about anyone.
- It does not read, change or delete existing videos, comments, subscribers or account settings.
- It does not sell or give data to third parties.
- It does not use cookies, analytics or ads.

## Google API data

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

Access can be removed at any time at https://myaccount.google.com/permissions
